Frequently asked questions

A few things to know before using the tools.

Are the results guaranteed?

No. Bottleneck scores and FPS figures are estimates based on models and available inputs. Real performance can vary with game updates, drivers, settings, cooling and other system factors.

Do I need to create an account?

No account or sign-up is required to use the free tools on this site.

How are estimates calculated?

Each tool uses its own inputs and assumptions. Read the methodology page for more about the approach and its limitations.
