How this estimate works

1. Benchmark-normalized scoresCPU scores use Tom’s Hardware’s 2026 1080p gaming hierarchy. GPU scores use its 2026 native-raster hierarchy with the RTX 5090 as the 100-point reference.
2. Resolution-aware GPU dataFor benchmarked GPUs, 1080p, 1440p, and 4K values come directly from the same 2026 hierarchy. Older/unbenchmarked models use clearly marked estimates.
3. Target-FPS fitThe model compares requested FPS with a scenario capacity estimate. Higher targets increase modeled demand, while CPU and GPU scaling are treated differently.
4. System context is a health checkRAM, storage, and background load can affect stutter and frame-time consistency, but their exact FPS impact varies too much to fake as one universal multiplier.
5. What this cannot knowEngine behavior, graphics settings, ray tracing, upscaling, frame generation, RAM configuration, drivers, thermals, background load, and the specific game can change the result.
Sources: Tom’s Hardware CPU Hierarchy 2026 · Tom’s Hardware GPU Hierarchy 2026 · 2026 Steam RAM usage trend · Related: CPU vs GPU Bottleneck guide · FPS Calculator · GPU Comparison
SystemFit model v2: Game-specific profiles describe workload tendencies and are not substitutes for measured FPS benchmarks. This is a benchmark-informed planning tool, not a live hardware test. Direct benchmark values are used where available; older hardware may use bridged or estimated values. CPU and GPU indices use separate reference hardware and are not equivalent to each other or to FPS. Native-resolution raster data does not account for DLSS/FSR/XeSS, frame generation, ray-tracing mode changes, or every game engine. Use the result as a planning estimate, not a guarantee.
