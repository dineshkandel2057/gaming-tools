💡 What does this mean?

Data note: Some hardware entries are benchmark-verified while others remain provisional until they can be mapped to a consistent test source. Verified source scores are stored separately from the internal calculator scale. Important: This calculator provides generalized estimates based on relative hardware performance and workload assumptions. Bottleneck and pressure values are not measured hardware utilization and should not be interpreted as exact FPS loss. Real-world performance varies with game engine, graphics settings, drivers, RAM, cooling, background applications and other system factors.
