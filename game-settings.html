How the recommendation works

The tool is designed to be explainable. It should tell the user why a setting was lowered or raised instead of returning an unexplained AI answer.

1. Hardware pressure

GPU tier, CPU tier and available VRAM influence which settings are sensible at the selected resolution.

2. Game profile

Each supported game has a lightweight performance profile for CPU load, GPU load, VRAM demand and visual-costly features.

3. Your goal

Maximum FPS, balanced quality and best visual quality intentionally produce different recommendations from the same PC.

About the estimates: SystemFit is not claiming that one formula can replace real-world benchmarks. V1 uses modeled ranges so the tool can be useful while remaining honest about uncertainty. As we collect better benchmark data, the model can be calibrated and expanded.
