How to use the result

Start with the suggested preset, then change one setting at a time. If GPU usage is near full load, lower GPU-heavy options such as resolution, ray tracing, shadows and volumetrics. If GPU usage is low while one or more CPU threads are heavily loaded, the game may be CPU-limited and lowering graphics quality may not add much FPS.

For a more focused diagnosis, try the FPS Calculator, Bottleneck Calculator or read the graphics settings guide.

How this tool works

The SystemFit PC Game Settings Optimizer turns your game, hardware and target FPS into a practical starting preset. Instead of treating every graphics option as equally important, it focuses on the settings that commonly change GPU workload, visual quality and performance. The recommendation can include a broad preset plus guidance for resolution, upscaling, frame generation, shadows, effects and other demanding options where the selected workload supports them.

The goal is not to find one “perfect” preset. A good starting point depends on whether you value image quality, stable frame times, competitive responsiveness or simply reaching a specific FPS target. Use the recommendation as a baseline, launch the game, then make small changes based on your actual performance.

How to read the result

Start with the suggested preset and target FPS, then look at the individual settings underneath it. If GPU usage is near full load, lowering resolution or GPU-heavy effects is generally more useful than randomly changing CPU-related options. If GPU usage is low while a CPU thread is heavily loaded, lowering visual quality may have little effect because the workload may be CPU-limited.

Change one major option at a time so you can tell what actually helped. If you want a more numerical estimate, compare the setup in the FPS Calculator. For deeper explanations of individual settings, read Which Graphics Settings Affect FPS Most?.

Limits of this estimate

The optimizer does not run the game or measure your exact frame times. Actual performance can change with patches, drivers, background tasks, thermals, shader compilation, crowded scenes and settings that the model cannot fully observe. A preset that works well in one area of a game may be too demanding in another. Treat the output as a sensible starting point, then validate it in the game itself. The best final setting is the one that meets your visual preference and performance target consistently.

Frequently asked questions

Should I use the recommended preset exactly?

No. Use it as a starting point, then adjust individual settings to match your visual preference and real FPS.

Which settings should I lower first when FPS is low?

Start with demanding GPU options such as resolution, ray tracing, shadows and volumetric effects, depending on the game.

Why does lowering graphics sometimes barely change FPS?

If the game is CPU-limited, reducing GPU workload may not remove the actual performance limit.

Is upscaling always worth using?

Not always. It can improve performance by rendering at a lower internal resolution, but image quality and latency trade-offs depend on the game and mode.

How can I check whether the recommended settings are realistic?

Test them in a demanding scene and compare the result with the FPS Calculator and Bottleneck Calculator.
